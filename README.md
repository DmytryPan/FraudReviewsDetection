## О проекте

Данный репозиторий содержит реализацию исследования по задаче бинарной классификации текстов отзывов с целью выявления мошеннических (fake) и достоверных (genuine) рецензий. Проект включает полный ML-пайплайн: от предобработки данных и балансировки выборки до обучения глубоких нейронных сетей и традиционных моделей машинного обучения.

## Методология

### 1. Предобработка текста
Основные шаги:
- Приведение к нижнему регистру
- Удаление спецсимволов и пунктуации (кроме апострофа)
- Раскрытие сокращений (contractions.fix)
- Токенизация (NLTK word_tokenize)
- Лемматизация (WordNetLemmatizer)
- Удаление стоп-слов

### 2. Векторизация и эмбеддинги
- TF-IDF для традиционных моделей (Logistic Regression, SVM, RF, etc.)
- GloVe 300D предобученные эмбеддинги для нейросетевых архитектур
- Построение словаря с токенами PAD и UNK

### 3. Балансировка данных 

#### 3.1. KMeans Undersampling + RAPIDS 
Для борьбы с дисбалансом реализован метод кластерного андерсэмплинга мажоритарного класса:

1. Применяем KMeans (cuML) к выборке мажоритарного класса
3. Отбор производится по ближайшим к центроидам экземплярам
4. Объединяем с полной выборкой миноритарного класса

Преимущества:
- Сохранение репрезентативности данных через кластеризацию
- Ускорение вычислений за счёт GPU (RAPIDS cuML)
- Улучшение метрик для миноритарного класса без переобучения

#### 3.2. Аугментация миноритарного класса с использованием LLM
Увеличение количества экземпляров миноритарного класса за счет генерации похожих фейковых отзывов.
LLM: Microsoft Phi-2


### 4. Архитектуры моделей

#### Традиционные ML-модели (scikit-learn / cuML)
| Модель | Описание |
|--------|----------|
| LogisticRegression | Линейная модель с L2-регуляризацией |
| RandomForest | Ансамбль решающих деревьев |
| SVC | Машина опорных векторов с RBF-ядром |
| ComplementNB | Наивный Байес для текстов |
| KNeighborsClassifier | Метод k-ближайших соседей |
| SGDClassifier | Стохастический градиентный спуск |

#### Нейросетевые архитектуры (PyTorch)
| Архитектура | Ключевые компоненты |
|-------------|-------------------|
| Simple LSTM | Embedding -> Dropout -> LSTM(256) -> Linear |
| Bidirectional LSTM | Двунаправленный LSTM для контекста в обе стороны |
| Simple GRU | GRU-ячейки как альтернатива LSTM |
| LSTM + CNN | LSTM -> CNN(128 фильтров, kernel=3) -> Pooling |
| LSTM + Parallel CNN | Параллельные ветви LSTM и CNN с конкатенацией |

Все модели используют Dropout (0.25) и Xavier/Orthogonal инициализацию весов.
